# Báo cáo nghiệm thu Giai đoạn 3 — HanoiFood

Ngày xác minh: **09/11/2026**. **GIAI ĐOẠN 3 HOÀN THÀNH** trong phạm vi nền tảng frontend đã yêu cầu. Frontend ở `frontend/`, kết nối backend thật; chưa triển khai công khai hoặc tự làm tiếp Giai đoạn 4–7.

1. **Kết luận:** React frontend chạy được qua Vite dev và production preview. Bản production cuối cùng đã qua TypeScript strict, ESLint, formatter, unit/component và Playwright E2E với backend/MySQL thử nghiệm thật. Không dùng test SKIPPED để tính PASS.

2. **Tính năng:** Landing đầy đủ, danh mục món ăn từ GET /food-items, danh sách nhà hàng thật, lọc/pagination local có nhãn rõ, chi tiết nhà hàng và thực đơn thật; login/register CUSTOMER; hồ sơ tài khoản đọc thật; password visibility; đổi mật khẩu; logout/logout-all; khôi phục phiên; single-flight/cross-tab refresh; thông báo tiếng Việt; bốn workspace và guard; loading/skeleton/empty/network/error/403/404; global và route error boundary. Không có số liệu dashboard, đơn hàng hoặc nhà hàng giả trong runtime.

3. **Cấu trúc:** `src/app` router/guards/styles; `components/ui`, `feedback`, `layout`; `features/auth`, `public`, `account`, `workspace`; `lib/api`, `lib/runtime`; `types/domain`; test cạnh module và `e2e/`. TypeScript strict, không any trong code dự án. Fetch tập trung, TanStack Query cho server state, React Hook Form/Zod cho form và response. Các trang lazy-load thành chunk public/auth/account/workspace riêng. Xem [kiến trúc](phase3-architecture.md).

4. **Route:** Đủ các đường dẫn public, /account, /account/change-password, CUSTOMER, RESTAURANT, DRIVER và ADMIN theo yêu cầu. GuestOnlyRoute/AuthenticatedRoute/RoleProtectedRoute nằm dưới SessionGate; anonymous → login, sai role → 403, login → dashboard theo Account server. Parent /restaurant, /driver, /admin chuyển tới dashboard; fallback hiển thị 404. [Danh sách route và trạng thái](phase3-routes.md) ghi rõ các trang nghiệp vụ Giai đoạn 4–7 chỉ là shell/giới thiệu chức năng, không giả là đã tích hợp CRUD.

5. **Design system:** Thương hiệu HanoiFood nền ngà/cam ấm/xanh lá đậm; token tập trung, Tailwind 4, font Be Vietnam Pro tự host kèm license, SVG món ăn tự tạo, không CDN ảnh/font. Có các primitive được yêu cầu: button/input/password/select/checkbox/card/badge/dialog/dropdown/tabs/toast/alert/skeleton/spinner/empty/error/pagination/breadcrumb/avatar/page-header/confirm-dialog. Label/error liên kết, ARIA state, skip link, focus visible, dialog trap/return focus, keyboard tabs và reduced motion. Không tuyên bố đã có chứng nhận WCAG hoặc audit screen reader toàn diện.

6. **Auth flow:** Access token/Account chỉ trong memory. Khởi động một lần kể cả StrictMode: CSRF → refresh cookie → /auth/me → render đúng role. Web Locks khóa toàn bộ CSRF + thao tác auth giữa các tab cùng origin; Promise single-flight trong tab. BroadcastChannel chỉ truyền changed/signed-out, không token/role/ID/email. Logout/chuyển identity cancel query và clear cache; response riêng tư cũ không được nhận sau đổi identity. Network failure khác anonymous, có retry và không hiển thị dashboard cũ khi boot/unavailable.

7. **API integration:** Dùng đúng tám Auth API, /auth/me, GET public food-items/restaurants/restaurant-food-items và GET profile từ ID server. Không gửi role, accountId/profileId hoặc confirmPassword trong đăng ký. Token dùng Bearer cho API bảo vệ; public GET không kèm Bearer cũ. Credentials include, CSRF header đúng tên server, timeout 15 giây và AbortSignal. GET 401 chỉ refresh/retry một lần; mutation không tự phát lại. Đổi mật khẩu/logout-all kiểm tra access an toàn trước khi gửi mutation. [Chi tiết payload, cookie và giới hạn backend](phase3-api-integration.md).

8. **Unit/component/integration cấp frontend:** **58 PASS / 0 FAIL / 0 ERROR / 0 SKIPPED**, 8 file test. Bao phủ validation Unicode/byte BCrypt/confirm; auth/session/single-flight/cache/identity; GET retry và không replay mutation; lỗi HTTP/network/cancel; CSRF; bốn role redirect/guard; login/register/loading/error/password visibility; dialog focus/Escape, tabs, checkbox, ErrorBoundary, 403/404/empty; danh mục thật/dedup và tiền VND. Mock chỉ có trong test, không có mock runtime. Chứng cứ: logs/unit-results.json và unit.log.

Đã kiểm chứng public catalog/menu/category từ backend; đăng ký/login CUSTOMER; reload; logout và JWT cũ bị 401; RESTAURANT/DRIVER/ADMIN đúng layout; frontend guard và backend 403; đổi password/old password bị từ chối/new password login; logout-all thu hồi phiên browser thứ hai; hai tab reload/refresh đồng thời không replay-revoke; empty/403/404/network recovery. Không tính lượt dev trước đó thành thêm test độc lập. Trace/video tự động tắt để không ghi secret.

10. **Responsive:** Bốn ca E2E ở **375/768/1024/1440px**, mỗi ca kiểm tra home/login/register + bốn dashboard + account ở bốn role: **44 kiểm tra overflow và 44 ảnh production**. Đợi nội dung thật hiển thị trước đo/chụp, không chấp nhận màn hình lazy loading làm bằng chứng UI hoàn thiện. Không phát hiện tràn ngang; mobile navbar, role drawer và keyboard Escape/return focus PASS. Đã xem mẫu ảnh mobile landing/login và desktop ADMIN bằng công cụ đọc ảnh; không tuyên bố đã kiểm thử WebKit/Firefox hoặc mọi thiết bị thật.

13. **Lỗi/điểm tích hợp đã xử lý:** npm.ps1 bị execution policy chặn → dùng npm.cmd, không đổi policy. Cookie Path=/auth không khớp prefix /api → rewrite đúng /api/auth, giữ Secure/HttpOnly/Strict và đường dẫn xóa cookie. Proxy giữ Host để bảo toàn same-origin local, không tắt CORS/CSRF hoặc đổi Origin. Không tự retry POST; xác minh/refresh trước mutation bảo vệ khi access hết hạn. GET retry vẫn 401 thì xóa phiên. Parent route không để shell trống. Test responsive chờ đúng page thay vì bắt nhầm heading footer trong lúc lazy load. Danh mục public lấy từ backend và không giả thành bộ lọc nhà hàng theo category.
